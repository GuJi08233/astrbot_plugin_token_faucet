# astrbot_plugin_token_faucet

签到赚取游戏币，并提现为链上 ERC-20 代币。

默认对接 Sepolia 测试网上的「游戏币」(`✦`)：
[`0x64bf89340562ab4fe829a481e6797b012664425b`](https://sepolia.etherscan.io/token/0x64bf89340562ab4fe829a481e6797b012664425b)

## 指令

| 指令 | 说明 |
| --- | --- |
| `/签到` | 每日签到，随机获得 1–3 个币（可配置） |
| `/绑定钱包 <地址>` | 绑定收款地址，之后提现无需再填地址 |
| `/解绑钱包` | 解除绑定 |
| `/余额` | 查询自己的余额；已绑定钱包时同时显示链上余额与合计 |
| `/钱包` | 查看个人信息：余额、累计签到/提现、绑定地址 |
| `/转账 @某人 <数量>` | 插件内转账，仅转移插件余额，不上链、不占提现额度 |
| `/提现 <数量>` | 提现到已绑定地址 |
| `/提现 <地址> <数量>` | 提现到指定地址，无需提前绑定 |
| `/提现记录` | 查看最近 5 条提现记录 |
| `/游戏币` | 公开信息：代币名称、符号、总量、合约地址、分发钱包余额与今日剩余提现额度 |
| `/排行榜` | 链上持有排行榜（前 10），仅统计已绑定钱包的用户，按绑定地址的实时链上余额排序 |

## 这个币的特殊之处：decimals = 0

该代币的 `decimals` 为 **0**，也就是**不可拆分**：链上的 `1` 就是 1 个币，没有小数位。

因此：

- 提现数量只能是正整数，`/提现 1.5` 会被拒绝；
- 配置里的所有数量（日限额、签到区间、单次上下限）都直接对应链上数量，无需换算。

若将来更换成别的代币，**必须**同步修改配置中的 `token_decimals` 为该合约的真实值。填错会让转账金额相差若干个数量级。

## 部署前准备

插件只做 `transfer` 转账，不涉及增发或销毁，因此**不需要**使用合约 owner 账户——请新建一个专用的分发账户：

1. **准备分发钱包**：新建一个专用账户，把私钥填入配置的 `private_key`。
2. **充值代币**：向该地址转入游戏币，每日按需补充到当日限额（如 1000）。
3. **充值 Gas**：该地址还需持有少量 Sepolia ETH 支付转账 Gas，否则转账会失败。可从公共水龙头领取。
4. **配置 RPC**：默认使用公共节点，限流较严。生产环境建议换成 Alchemy / Infura 的专属节点。

日常运维只需保证分发钱包的**代币余额 ≥ 当日限额**。用 `/游戏币` 可直接查看该余额；Gas 余额不在指令中展示，请自行在区块浏览器关注。

## 安全须知

- 私钥以**明文**保存在 `data/config/astrbot_plugin_token_faucet_config.json`。
- 请**只**使用专用的测试网钱包，切勿填入持有主网资产的私钥。
- 本插件不注册任何 LLM 工具，提现只能由用户显式发送指令触发，模型无法自主调用。

## 额度与一致性

- **每日全局限额**：所有用户当天提现总量的上限，默认 1000。按配置的时区偏移（默认 UTC+8，即北京时间 0 点）重置。
- **失败即退款**：广播失败或链上回滚时，代币退回用户余额，并释放其占用的当日额度。
- **超时不退款**：交易已广播但等待确认超时的，记录保持「已广播」，因为它仍可能被打包。
- **崩溃可恢复**：进程若在扣款与广播之间退出，重启时会自动退回这些卡在 `pending` 的记录。

余额扣减与额度检查在同一个 `BEGIN IMMEDIATE` 事务内完成，链上发送串行化以避免 nonce 冲突——并发提现不会击穿限额，也不会互相顶掉交易。

## 数据存储

SQLite 数据库位于 `data/plugin_data/astrbot_plugin_token_faucet/faucet.db`，含三张表：

- `users`：余额、绑定地址、签到与提现累计
- `withdrawals`：提现流水与链上状态
- `checkins`：签到记录，`(user_key, day)` 主键保证每人每天仅一次

用户身份为 `平台ID:发送者ID`，不含群号——同一用户在不同群共用同一个余额。

## 测试

```bash
python -m pytest tests/ --asyncio-mode=auto -q
```

测试覆盖签到幂等、并发签到、余额不足拒绝、退款与重复退款、已确认不可退款、并发提现的日限额守恒、额度按日重置、崩溃恢复。均为纯本地 SQLite 测试，不访问网络。
